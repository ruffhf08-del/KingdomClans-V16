## 📥 Step 1: Download (1 minute)

### Option A: Download APK (Easiest)
```
1. Go to: https://github.com/ruffhf08-del/KingdomClans-V16/releases
2. Click latest release
3. Download: app-debug.apk (50 MB)
4. Wait for download...
```

### Option B: Download ZIP (For Developers)
```
1. Go to: https://github.com/ruffhf08-del/KingdomClans-V16
2. Green "Code" button → Download ZIP
3. Extract folder
4. You have full source code!
```

---

## 💻 Step 2: Install (2 minutes)

### On Your Phone

```
1. Transfer APK to phone
   (via USB cable or Bluetooth)

2. Open file manager on phone

3. Find KingdomClans APK file

4. Tap to open

5. Click "INSTALL"

6. Wait for installation... ⏳

7. Click "OPEN" when done

8. GAME LAUNCHES! 🎮
```

### Important Settings

Before installing, enable:
```
Settings 
  → Security 
    → Unknown Sources 
      → Toggle ON ✓
```

---

## 🎮 Step 3: Start Playing (1 minute)

### First Launch

```
1. Tap "Kingdom Clans" icon

2. Wait 30-60 seconds for loading

3. Tap "New Game"

4. Enter your village name

5. Click "Create"

6. Tutorial starts...

7. START PLAYING! 👑
```

## 🏰 Step 4: Learn the Basics (2 minutes)

### First 5 Minutes

**Minute 1: Explore Village**
- Look around your village
- See all the buildings
- Notice the resources

**Minute 2: Collect Resources**
- Gold mines generate gold ✓
- Elixir drills collect elixir ✓
- Watch them fill up

**Minute 3: Build Something**
- Tap empty space
- Select a building
- Place it
- Click "Build"

**Minute 4: Train Troops**
- Go to Barracks
- Train a Barbarian
- Wait for training
- See troop in Army

**Minute 5: Attack Someone**
- Click "Attack"
- Pick a village
- Deploy troops
- Watch battle
- Earn loot! 🏆

## 💡 Pro Tips

### Building Strategy
1. **Prioritize Town Hall** - Unlocks new buildings
2. **Build Resource Generators** - Gold & Elixir
3. **Build Defenses** - Protect from attacks
4. **Arrange Efficiently** - Maximize space

### Army Strategy
1. **Train Balanced** - Mix of units
2. **Use Heroes** - Powerful units
3. **Research Upgrades** - Stronger troops
4. **Save Army** - Keep trained for defense

### Battle Strategy
1. **Scout First** - See village layout
2. **Plan Attack** - Know troop placement
3. **Manage Resources** - Don't waste troops
4. **Study Defenses** - Know enemy buildings

### Resource Management
1. **Collect Regularly** - Check every 2 hours
2. **Spend Wisely** - Don't waste on weak buildings
3. **Store Safely** - Upgrade storage
4. **Farm Efficiently** - Attack for loot

## 🆘 Common Questions

### Q: Where do I get resources?
**A:** From mines/drills. They auto-generate. Collect from storage buildings!

### Q: How do I upgrade buildings?
**A:** Click building → Tap "Upgrade" → Click "Upgrade" → Wait for timer

### Q: How do I attack others?
**A:** Click "Attack" → Choose village → Tap troops to deploy → Watch battle

### Q: Can I play offline?
**A:** YES! Full offline gameplay supported

### Q: Can I play with friends?
**A:** YES! Local multiplayer via Bluetooth/WiFi (upcoming)

### Q: Where are my saves?
**A:** Auto-saved locally on phone. Check Settings → Data

### Q: Game crashed. What to do?
**A:** Force stop app → Clear cache → Restart phone → Open again

### Q: How many GB storage needed?
**A:** 100MB minimum, 200MB+ recommended
