## 🔧 Building from Source

### Prerequisites
```bash
# Java 11
java --version

# Android SDK (via Android Studio)
# Gradle (auto-downloaded)

# Git
git --version
```

### Build Steps
```bash
# Clone
git clone https://github.com/ruffhf08-del/KingdomClans-V16.git
cd KingdomClans-V16

# Setup
bash setup.sh

# Build Debug APK
./gradlew assembleDebug

# Build Release APK (smaller, optimized)
./gradlew assembleRelease

# Output
# Debug: android/build/outputs/apk/debug/app-debug.apk
# Release: android/build/outputs/apk/release/app-release.apk
```

### Time Required
- First build: 5-10 minutes
- Subsequent: 2-3 minutes
- Depends on internet speed

## 🐛 Troubleshooting

### APK Installation Issues
```
❌ "Installation failed"
✅ Solution:
   1. Enable Unknown Sources in Settings
   2. Free up 100MB+ storage
   3. Restart phone
   4. Try again
```

### Game Crashes
```
❌ "App keeps crashing"
✅ Solution:
   1. Force stop: Settings > Apps > Force Stop
   2. Clear cache: Settings > Apps > Clear Cache
   3. Restart phone
   4. Reinstall app
```

### Performance Issues
```
❌ "Game is laggy"
✅ Solution:
   1. Lower graphics in settings
   2. Close background apps
   3. Free up RAM
   4. Update Android OS
```

### Build Failures
```
❌ "./gradlew: not found"
✅ Solution:
   chmod +x gradlew
   ./gradlew clean build
```
