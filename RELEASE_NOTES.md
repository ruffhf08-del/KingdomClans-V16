## 🚀 Installation

```bash
git clone https://github.com/ruffhf08-del/KingdomClans-V16.git
cd KingdomClans-V16
./gradlew assembleDebug
```

APK location: `android/build/outputs/apk/debug/app-debug.apk`

## 📱 System Requirements
- Android 5.0+ (API 21+)
- Minimum 100MB storage
- 2GB RAM recommended

3. Train troops including powerful dragons
4. Attack other villages for loot
