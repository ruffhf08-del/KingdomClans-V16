## 🔧 Troubleshooting

### APK Won't Install
```
❌ "Installation failed"
✅ Solution:
   - Clear Play Store cache
   - Free up storage (100MB+)
   - Restart phone
   - Enable Unknown Sources
   - Try again
```

### Game Crashes
```
❌ "App keeps crashing"
✅ Solution:
   - Force stop: Settings > Apps > Force Stop
   - Clear cache: Settings > Apps > Clear Cache
   - Reinstall game
   - Update Android OS
```

### Performance Issues
```
❌ "Game is laggy"
✅ Solution:
   - Lower graphics quality
   - Close background apps
   - Free up RAM
   - Reduce screen resolution
```
